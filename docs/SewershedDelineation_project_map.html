Load-bearing guardrails: (1) Polygon = dissolved union of served population units, not a pipe buffer — clean parcel boundaries for the demographic join. (2) Direction errors are flagged, not auto-corrected; geometry-first (line start = upstream), inverts are cross-checks. (3) A lift station at the sampling point is a terminal end of a gravity basin — trace it normally; never special-case pumped target sites. (4) Truth = agreement with expert manual delineation, not ground-truth accuracy; gravity-only (force-main-fed subbasins undercounted).
