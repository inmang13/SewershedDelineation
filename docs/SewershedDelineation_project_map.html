Load-bearing guardrails: geometry is the source of truth for pipe direction (line start = upstream); inverts/attributes are cross-checks only and never override geometry. Source data/ is immutable — every repair (midspan splits, flip/delete/extend, snaps) is applied in memory and flagged for the maintainer, never written back. Direction errors are flagged, not auto-corrected. Fixes are system-agnostic — the city specifics live only in config/CSV inputs, so the pipeline can run on a new city's network.
