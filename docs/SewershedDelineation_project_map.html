Guardrails: direction errors are flagged, never auto-corrected — the sole repair path is the human-approved decisions file, and a snap that merges nothing fails loudly. Truth polygons are only edited for digitizing mistakes verified against the pipe layer, never toward model output. Domain rule (07-02): a lift station at the sampling point is a terminal end of a gravity basin — treat as a normal target, no pumped-site special-casing.
