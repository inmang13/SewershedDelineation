2What I figured out

The equivalence gate is the day's load-bearing trick. Instead of trusting the run.py rewrite, all 24 validation sites were traced through it and each polygon compared to the committed reference by symmetric difference (area in one shape but not the other — zero means identical). All 24 came back 0.0000 ft² — the paper's number provably untouched. The gate also caught a real bug: pandas' type inference silently corrupted zero-padded IDs (02201 → 2201.0); fixed with dtype=str.

P2-4 was a free fix. The production resolver (with the false-headwater guard — avoids snapping to a dead-end stub node that only looks like the top of the network) and the validation sweep's bare nearest-node snap pick the identical node and pipe set on all 24 sites. Unifying them can't move the number.

The QA subsystem's weaknesses are now quantified, not vibes. Severity is a hard-coded label per check (no scoring); ~85% of the 1,066 flags (isolated_manhole 522, invert_conflict 267, missing_direction 112) got zero reviewer attention — by-design bulk; the one type that drew review effort (snap_gap) ran ~1 true positive in 44 by Grace's own comments. And the repair machinery (qa_review/pipe_edits/pipe_splits) is welded into the graph loader — every delineation run re-applies the human decisions CSV in memory — so "keep QA private" was never an option; only the flag-emission side is separable.

Demographics was missing from the release plan by staleness, not decision — built 07-10, three days after the Phase 9 plan (07-07). Nobody ever chose to exclude it.

3Decisions in play (all logged in decision_log 2026-07-12)

  • Thin run.py, not extraction. The spine replicates the validated per-site loop rather than refactoring the runners the paper's number rides on. The shared-function extraction is its own parked, re-validated PR.
  • P2-7 pumped-guard refused. Its premise is the exact error corrected 2026-07-02 (lift station at the sampling point traces normally). Left: drop it, or redefine as the force-main-fed-subbasin detector.
  • Anonymization: site name scrubbed from all text; data paths renamed on disk + in config (parcels_poly, census_blocks); named local feature genericized ("trunk interceptor"); FIPS codes kept (Census pull needs them); name-bearing binary gpkg untracked.
  • Phase 9 rescope — five calls: (1) demographics in scope — ship the end-to-end WBE pipeline, novelty framing stays on the validated delineation; (2) figures = de-identified screenshots OK (no basemap, no IDs, no coordinates, no data files); (3) JOSS submission optional — build JOSS-ready, mint Zenodo DOI, decide later; (4) QA ships as-is with honest docs, classification rework = seeded post-release track; (5) demographics demo = real-geography walkthrough + scripted de-identified render, no fake census mini-cache.
